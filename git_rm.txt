Question 1. Does the file exist on your computer after running the git rm command?
Answer. No

Question 2. When must you use git rm vs. manually deleting a file?
Answer. When you want github to track that you deleted the file. 

Question 3. How can you undo restore an accidentally deleted, by the git rm command, file?
Answer.  git restore <filename>
